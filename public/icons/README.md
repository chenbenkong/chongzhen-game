# PWA / 品牌图标资源 · 崇祯·宦海浮沉模拟器

本目录是站点的图标与 PWA 资源层，全部由 `scripts/generate-icons.py`（仅依赖 Pillow）以同一套设计规则程序化绘制：**墨黑圆角印章底（#0A0807）+ 极细古金内框（#C5A55A）+ 居中金色「明」字**，字体在运行时按候选列表（SimSun → 微软雅黑 → 黑体 → 华文楷体 → Songti → Noto Serif CJK）取第一个存在者。逐项说明：`favicon.svg` 是手工编写的矢量源（内联、无外部引用，浏览器标签页与 manifest 的 `image/svg+xml` 条目使用它）；`favicon-32.png`（32×32，圆角透明底，字形略微放大、边框内收，以保证 16–32px 下仍可辨认）是传统 PNG favicon 回退；`apple-touch-icon.png`（180×180，**不透明**满幅方图，内框略收，因为 iOS 会自行裁圆角，透明角会被填黑）；`icon-192.png` 与 `icon-512.png`（圆角透明底）是 manifest 的常规图标，供安装提示、任务栏与应用列表使用；`icon-maskable-512.png`（512×512，满幅不透明）是 Android 自适应图标，内容已按安全区排布——「明」字限制在中心约 46% 区域内，因此无论系统套用圆形、圆角方形还是水滴形遮罩，字都不会被裁掉，只有装饰性金框的四个角可能被削去（视觉上仍然成立）；`../og-image.png`（1200×630）是社交分享卡片，墨黑底 + 中心极淡暗红径向光晕 + 内缩 24px 的双层细金框 + 金色大标题「崇祯 · 宦海浮沉」+ 羊皮纸色副标题「明末官场沉浮模拟器」+ 底部暗色小字「从科举童生到朝堂大员 · 1628–1644」。

## 重新生成

在仓库根目录执行：

```bash
python scripts/generate-icons.py
```

脚本会重新绘制并覆盖 `favicon-32.png`、`apple-touch-icon.png`、`icon-192.png`、`icon-512.png`、`icon-maskable-512.png` 与 `../og-image.png`；所有图形先在 4× 目标尺寸下绘制，再用 LANCZOS 降采样以获得干净边缘。**它不会读取也不会改写 `favicon.svg`**——该矢量文件是手工维护的设计源，若改动图标设计，请同步手工修改 `favicon.svg` 与脚本中的调色板/绘制参数。若机器上找不到列表中的任何 CJK 字体，脚本会抛出错误并列出所有尝试过的路径，此时安装其中任一款字体，或把本机字体路径加入脚本的 `FONT_CANDIDATES` 即可。
